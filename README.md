# ArchNet · Audio Module

Audio settings for an options menu: volume and mute for music and game sounds, applied at once and saved.

- Unity **6000.0** or newer · Needs `com.unity.ugui`.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/ModuleAudio.git
```

## Use

Drop the **ModuleAudio** prefab (`Runtime/Resources/Prefabs`) into your menu canvas. From code: `SetMusicVolume(0.5f)`, `SetSoundMuted(true)`.
